# منابع تصاویر ثابت

این پوشه دارایی‌های تصویری ثابت داشبورد را نگه می‌دارد تا صفحه برای نمایش
چهره‌ها، پرچم‌ها و نشان‌ها به فراخوانی زندهٔ سرویس‌های تصویری وابسته نباشد.

- `portraits.json` منبع، پدیدآور/اعتبار و وضعیت مجوز هر تصویر را ثبت می‌کند.
- تصاویر Wikimedia Commons از شناسهٔ منبع‌دار Wikidata هر شخص گرفته شده‌اند.
- برای پرونده‌های فاقد تصویر Wikidata، فقط تصویر صفحهٔ رسمی، حساب عمومی رسمی یا
  منبع زندگی‌نامه‌ای همان پرونده استفاده شده است. عبارت «حقوق تصویر نزد منبع»
  به معنی مجوز آزاد نیست؛ حقوق تصویر نزد منبع نام‌برده باقی می‌ماند.
- پرچم‌ها فایل‌های محلی FlagCDN/Wikimedia Commons هستند. نشان‌های سازمانی از
  Wikimedia Commons و دادهٔ هویتی Wikidata گرفته شده‌اند؛ نشان تجاری یا رسمی
  صرفاً برای شناسایی نهادی استفاده می‌شود.
- برای نامی که تصویر قابل اتکای آن پیدا نشده، تصویر خنثی و صریحاً مشخص‌شده به
  عنوان جایگزین باقی می‌ماند؛ تصویر حدسی یا متعلق به همنام منتشر نمی‌شود.

فایل `scripts/build-static-media.py` این دارایی‌ها و دو مانیفست را بازسازی
می‌کند. هر تغییر باید با بازبینی بصری و حفظ منبع انجام شود.
